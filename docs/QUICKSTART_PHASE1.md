# Phase 1 Quick Start: From Zero to Testing

**Complete setup in 45 minutes | No Supabase experience required**

1. **Accounts** (all free tier):

## Step-by-Step Setup

### 1️⃣ Create Supabase Project (5 min)

**Go to**: https://supabase.com/dashboard

1. Click **"New Project"**
2. Fill in:
   - Name: `xhire`
   - Password: Generate strong password (copy it!)
   - Region: Closest to you
3. Wait for setup (5-10 min, go next while waiting)
4. Go to **Settings → Database**
5. Copy connection string (URI format)
6. Go to **SQL Editor** → **New Query**
7. Paste:
   ```sql
   CREATE EXTENSION IF NOT EXISTS vector;
   ```
8. Click **Run**

**Save these**:
- Database URL (connection string)
- Database password

---

### 2️⃣ Setup Claude API (3 min)

### 6️⃣ Create .env File (5 min)

**In `backend/` folder**, create `.env` file:

```bash
# Database (from Supabase)
DATABASE_URL=postgresql://postgres:YOUR_PASSWORD@YOUR_HOST:6543/postgres?pgbouncer=true&schema=public

# AI (from Claude)
ANTHROPIC_API_KEY=sk-ant-YOUR_KEY

# Speech-to-Text (from Deepgram)
DEEPGRAM_API_KEY=YOUR_KEY

# Storage (from Supabase)
SUPABASE_URL=https://YOUR_PROJECT.supabase.co
SUPABASE_ANON_KEY=YOUR_KEY

# Auth (from Clerk)
CLERK_PUBLISHABLE_KEY=pk_test_YOUR_KEY
CLERK_SECRET_KEY=sk_test_YOUR_KEY

# Video (from Stream.io)
STREAM_API_KEY=YOUR_KEY
STREAM_API_SECRET=YOUR_SECRET

# Other
PORT=4000
NODE_ENV=development
CLIENT_URL=http://localhost:3000
```

Replace `YOUR_KEY`, `YOUR_PASSWORD`, `YOUR_HOST`, `YOUR_PROJECT` with actual values.

### 7️⃣ Create Frontend .env (2 min)

Replace values from Supabase, Clerk, and Stream.io.

### 8️⃣ Install & Setup Backend (10 min)

```bash
# Go to backend folder
cd backend

# Install dependencies
npm install

# Generate Prisma client
npm run prisma:generate

# Create database tables
npm run prisma:push

# Seed test data
npm run prisma:seed

# Start server
npm run dev
```

**Expected output**:
```
✅ Server started on port: 4000
✅ PostgreSQL (Prisma) connected successfully
✅ Using Supabase PostgreSQL database
```

## Common Issues & Fixes

### "Connection refused" on backend startup
- Check DATABASE_URL is correct
- Verify Supabase project is running
- Check pgbouncer=true in connection string

### "Invalid Clerk key"
- Verify CLERK_SECRET_KEY matches dashboard
- Check no extra spaces in .env
- Restart backend after editing .env

### Frontend doesn't load
- Check Node.js version (must be 18+)
- Check port 5173 is free
- Try: `npm run dev -- --port 3000`

### No Claude questions appearing
- Check ANTHROPIC_API_KEY is set
- Check API key has quota in Anthropic console
- Check Claude returns in backend logs

## Next: Understanding the Architecture

### What's Happening When You Create Interview?

```
1. Frontend sends resume + JD to backend
   ↓
2. Backend parses with Claude
   ├─ Extracts skills from resume
   ├─ Stores in PostgreSQL
   └─ Returns to frontend
   
3. Frontend shows "Start Interview"

4. User clicks "Start"
   ↓
5. Backend calls Claude with context
   ├─ Resume chunks from PostgreSQL
   ├─ Job description
   └─ Generates 3 progressive questions
   
6. Frontend displays questions one by one

7. User answers via text (or voice with Deepgram)
   ├─ Deepgram transcribes (WebSocket)
   └─ Answer sent to backend
   
8. Backend evaluates with Claude
   ├─ 4 dimension scoring (technical, etc)
   ├─ Returns feedback + next question
   └─ Stores in PostgreSQL
   
9. Frontend shows evaluation

10. After all questions, generates final report
    ├─ Enqueues async job
    └─ Stored evaluation in database
```
